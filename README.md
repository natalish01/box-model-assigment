# CSS Box Model & Layout Cheat-Sheet

ამ რეპოზიტორიუმში წარმოდგენილია სრული საგანმანათლებლო სახელმძღვანელო და ვიზუალური Cheat-Sheet დამწყები დეველოპერებისთვის, რომელიც ეძღვნება CSS-ის ერთ-ერთ ფუნდამენტურ კონცეფციას — **Box Model**-სა და განსხვავებას `content-box`-სა და `border-box`-ს შორის.

##  პროექტის შიგთავსი
* **index.html** — სემანტიკური HTML5 სტრუქტურა.
* **style.css** — სუფთა და თანამედროვე CSS3 სტილები, ვიზუალური დიაგრამები და დემო ბლოკები.

## 🛠️ ძირითადი თემები
1. **Box Model-ის 4 შრე:** Content, Padding, Border, Margin.
2. **დიდი დუელი:** `content-box` vs `border-box` ვიზუალური შედარება.
3. **პრაქტიკული პრობლემა:** როგორ ავიცილოთ თავიდან გაფუჭებული განლაგება (Broken Layout).
4. **ოქროს წესი (Best Practice):** საწყისი გლობალური რეზექცია თანამედროვე პროექტებისთვის.

## 💻 ტექნოლოგიები
* HTML5
* CSS3 (Flexbox, Grid)
